# Contributing

This repository is a **read-only public showcase**. Production source and ongoing development live in a **private repository**.

## Pull requests

- **Pull requests are not accepted** on `main` (or any branch).
- Please do not open PRs for features, fixes, or documentation changes here.

## Feedback and questions

You **can** open a [GitHub Issue](https://github.com/opanda01/sme-hr-management-showcase/issues/new/choose) using the **Portfolio feedback** template. Use it for showcase-related questions, suggestions, or portfolio feedback—not for production bug reports.

For product demos, partnerships, or commercial inquiries, visit **[kobik.dev](https://kobik.dev)**.
